\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

The CatSight AI system addresses the limitations of MSU-IIT's keyword-based document search by combining optical character recognition (OCR), vector embeddings, and a conversational interface driven by a large language model (LLM). It follows a retrieval-augmented generation (RAG) design: each issuance, scanned or digital, is converted to text page by page with Marker, whose Surya OCR 2 model reads every page while the Qwen3-VL vision-language model corrects tables, forms, and handwriting; the text is catalogued zero-shot, with map-reduce for long documents; and it is split into passages indexed for both semantic (cosine similarity on BGE-M3 embeddings) and keyword search. A question is answered by an agent that searches the library, fuses the two result lists with Reciprocal Rank Fusion, reranks them, and writes an answer that cites the exact pages it used. All models are open-weight: they are reached through OpenRouter because the proponents have no GPU server, but the institution can host the same weights on its own hardware. On a sample of seven documents, Marker with Qwen3-VL recovered 91\% of the facts read from the page images, without altering names or dates, while the repositories' own text layers yielded 40\% and nothing at all from scanned pages. In the usability evaluation of the defended prototype, CatSight AI's System Usability Scale score averaged 77.17, against 50.33 for the existing system. These results indicate that CatSight AI offers a more accurate, intelligent, and efficient way to retrieve MSU-IIT's documents than traditional keyword search.

\noindent\textbf{Keywords:} \emph{document retrieval system, optical character recognition, retrieval-augmented generation, vector similarity search, large language model, open-weight models}
